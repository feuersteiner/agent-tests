# Changelog

## [2.0.0] - 2026-09-14

### Removed

- The `--legacy` flag of the `sync` command. Use `--mode=classic` instead.

## [1.5.0] - 2026-08-02

### Added

- An `export` command that writes the queue to a JSON file.

## [1.4.2] - 2026-07-20

### Fixed

- `sync` no longer hangs when the remote returns an empty page.

## [1.4.1] - 2026-07-03

### Fixed

- Typo in the `--help` output of `status`.
