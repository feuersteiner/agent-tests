# No informal English

Customer-facing English prose uses formal vocabulary.

Contractions of conversational phrases such as “gonna”, “wanna”, and “gotta”
are unsuitable for customer-facing documentation. Use “going to”, “want to”,
and “have to” instead. Apply this rule to Markdown and plain-text content
under src/. Source code and internal files are outside its scope.
