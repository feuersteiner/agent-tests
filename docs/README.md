# agent-tests docs

The documentation site, built with Svelte 5, SvelteKit, and
[Bref-ui](https://github.com/feuersteiner/bref-ui). It deploys to GitHub Pages
on every push to `main`.

The home page covers configuration, test definitions, execution, and the community
catalog. Run `bun run --cwd docs check` and `BASE_PATH=/agent-tests bun run --cwd docs build`
before publishing.
